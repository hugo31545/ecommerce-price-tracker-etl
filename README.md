# ecommerce-price-tracker-etl

Pipeline ETL que compara o custo total real (preço, portes, câmbio, direitos aduaneiros e IVA de importação) de produtos em lojas de Portugal, Espanha, Reino Unido e EUA, e envia alertas de preço por e-mail.

Construído com **KNIME**, **Node-RED**, **PostgreSQL**, **Grafana**, **Docker** (SFTP e SMTP).
